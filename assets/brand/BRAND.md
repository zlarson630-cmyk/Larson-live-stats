# Larson Live Stats — brand standard

Approved identity: the angular Z symbol in the nine-sided badge supplied by the owner, rendered in red (#C91C2B). `larson-z-mark.svg` is a vector trace of the supplied raster mark, not a newly designed Z. Keep the source raster as the ultimate visual reference.

Product lockup: red Z badge followed by **LIVE STATS** in Barlow Condensed Bold Italic. Palette: red, black, white; do not use Jefferson school branding. Keep the Z mark reusable for other Larson products.

Documentation, PDFs and UI should use the approved mark. Do not replace with a generic polygon or substitute letter Z. If the actual Barlow Condensed Bold Italic font file is not available, disclose a fallback rather than claiming the exact font.
